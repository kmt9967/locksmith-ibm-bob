## Challenge (single track)
Improve a **specific developer workflow** (onboarding, debugging, code review, testing, maintenance, release/deployment). Define a problem where time/effort/errors are too high; build a **working prototype on a real or sample project** using IBM Bob 2.0. Leverage **Agent mode, parallel tasks, subagents, document understanding**. Demonstrate measurable impact.

## Eligibility-critical rules
1. **Bob IDE is required** and must be a *core component* of the solution. Bob Shell optional.
2. **`bob_sessions/` folder** in the repo with Bob IDE **task session summary screenshots** (PNG) — Tasks → select task → click task header → screenshot. Name e.g. `teqprotech_task01_<desc>_summary.png`. From **each team member**.
3. Repo must contain the code/files where Bob assisted.
4. **Public** code repository.
5. Data: bring your own; no client data, no confidential data, no personal information, no social-media data; public web data only if commercial use allowed (keep list of sites).
6. Submissions original and MIT-compliant.
7. Use the hackathon Bob account (`ibm-coding-challenge-uat`, us-east); 40 Bobcoins per participant, no top-ups.
